Project: Weather Checker App
API used: OpenWeatherMap Current Weather API
API documentation: https://openweathermap.org/api

Files included:
- index.html    (Group portfolio)
- app.html      (Main weather application)
- styles.css    (Shared styles)
- api.js, dom.js     (JavaScript logic using fetch / async-await)
- images/       (place team photos named member1.jpg, member2.jpg, ...)

Setup:
1. Sign up at OpenWeatherMap and obtain an API key.
2. Replace the placeholder API key in script.js: const API_KEY = 'YOUR_API_KEY_HERE';
3. Open index.html (best via a local web server, e.g. VSCode Live Server or `python -m http.server`).
4. Click "Open Weather Checker" and test.

Notes:
- For production hide API keys on a server; this client-side approach is OK for a class project.
- If you get CORS or network problems when opening files via file://, run a simple local server.
